# Simple Calculator

This is a simple, responsive calculator web application built as a single-page using HTML, Bootstrap 5, and JavaScript. This application allows the user to add two numbers and displays the result under 'Total Sales'.

## Setup and Installation

To set up this application, follow these simple steps:

1. **Download or Clone the Repository**: Ensure you have Git installed. Run the following command in your terminal:
   ```bash
   git clone <repository-url>
   ```
2. **Navigate to the Project Directory**: Move into the project directory:
   ```bash
   cd <project-directory>
   ```
3. **Open `index.html` File**: Use any modern web browser to open the `index.html` file. This is a client-side application and doesn't require a server to run.

## Usage

1. Enter the numbers you wish to add into the two input fields.
2. Click the "Calculate" button.
3. The result will be displayed under "Total Sales".
